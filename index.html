Come si installa

  1. Scarica il file per il tuo sistema.
  2. Avvialo (istruzioni per sistema qui sotto).
  3. Nella finestra scegli la cartella di installazione. Meglio una cartella fuori da OneDrive/iCloud e con almeno 10 GB liberi se hai una scheda NVIDIA.
  4. Attendi la barra di avanzamento: al termine trovi il collegamento sul Desktop.

Istruzioni per sistema

Windows
  1. Doppio clic su Installa.cmd.
  2. Se compare l'avviso blu di SmartScreen: Ulteriori informazioni → Esegui comunque. Il file non è firmato digitalmente.
  3. Se il browser blocca il download, scegli "Mantieni" dal menu dei download.
macOS
  1. Fai doppio clic su Installa-macOS.zip per decomprimerlo.
  2. Clic destro su Installa.command → Apri → conferma Apri. Serve solo la prima volta: l'app non è firmata da uno sviluppatore Apple, quindi un doppio clic semplice può essere bloccato.
  3. Serve Python 3.10+ (da python.org).
Linux

Da terminale, nella cartella del download: sh Installa.sh

Cosa viene installato

  • Il programma e le librerie necessarie, in un ambiente isolato dentro la cartella scelta.
  • Con una scheda NVIDIA, PyTorch con supporto GPU (download di alcuni GB); puoi rinunciarvi con la casella apposita e attivarlo dopo.
  • Se un componente è già presente non viene riscaricato.
